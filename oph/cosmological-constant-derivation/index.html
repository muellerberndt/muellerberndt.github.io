N readback frames the cosmological scale.

OPH’s cosmological constant proposal reads the universe's total capacity from the public records its own observers can preserve and recover. The cosmological scale is a global readback, not a local vacuum-energy sum.

OPH's direct global proposal is N = log M0(U_N): the logarithmic capacity supplied to a trial universe equals the logarithm of the public-record count read back by its own observers. Self-reference forces this equality only after the supplied quantity and the readback have been shown to be readings of one typed invariant. It first defines the observer-side count without Lambda: M0(q) = alpha(Gq), the maximum number of reachable public records that remain perfectly distinguishable through every authorized checkpoint. Across the whole terminal fiber the producer is set-valued, Fr,0(D) = {M0(q)}, and selector-free closure is Fr,0(D*) = {D*} with N_CRC = log D*. The complete declared source class contains no unique slack zero, so it emits no cosmic N. If a direct value and the physical horizon bridge were supplied, the independent horizon relation would give Lambda ell_*^2 = 3 pi / N_CRC and, with the scale certificate, Lambda_CRC = 3 pi / (G N_CRC).

On the exact reversible branch every authorized checkpoint continuation is injective, so M0(q) = |Xreach(q)|. The problem becomes exact CSP or model counting on one finite public checkpoint packet. Exact model counting does not select the missing global carrier or its finite-size slack law.

The separate source-forward common-load balance is N0(P_fwd) = pi exp(6 pi/(P_fwd alpha_U(P_fwd))) = 3.5321 x 10^122. It asks whether the screen and electroweak readings are two readings of one physical load. On the finite collar branch, a declared total reserve expectation P_fwd/4 and six-class equidistribution give one-class presence probability P_fwd/24. If one class is physically selected as the blocked event, its scalar-weighted receipt holds, and one normalized finite-cut survival factor acts on global capacity, then Npresence = N0(1-P_fwd/24) = 3.2921 x 10^122. The alternative NPoisson = N0 exp(-P_fwd/24) = 3.3001 x 10^122 requires an additional source-derived mean-count or projective-limit carrier. The measured-endpoint coordinate P_C belongs to a separate comparison branch and gives 3.53235 x 10^122; it is not the input to either reserve value.

Neither reserve branch is selected as cosmic capacity. The weighted Planck base-LambdaCDM chain maps its posterior through N_Lambda = 3 pi/(Lambda ell_P^2) = pi c^5/(hbar G Omega_Lambda H0^2) and gives the comparison coordinate 3.3129 x 10^122. Why closure is an equality

Start with a trial universe whose construction carries logarithmic record budget N. Let observers inside that trial universe determine the largest public-record code that survives every authorized checkpoint. Its logarithmic size is log M0(U_N).

OPH treats the construction and the internal readback as descriptions of one self-referential universe. Once a typed physical bridge proves that both expressions denote the same global record-capacity invariant, self-identity forces N = log M0(U_N). The equality is compulsory at that point.

What self-reference leaves to physics

Self-reference supplies no return map by itself. It does not identify a finite record carrier with a cosmological horizon, choose a reserve class, or prove that the resulting equation has one stable solution. The complete direct source class demonstrates this sharply: several admissible continuations have different fixed sets.

The common-load formula is a separate conditional balance. Once P and the declared running coupling are supplied, it returns the constant candidate N0. The finite-presence and Poisson factors encode different reserve carriers. Their physical selection and their action on global capacity require separate proofs.

Why de Sitter is the natural OPH screen

A de Sitter static patch gives an observer a finite cosmological horizon. That horizon has area, temperature, and finite entropy. For OPH, this makes it the natural cosmological screen: no observer has access to the whole universe at once, and the horizon bounds the data available to that observer.

The book route states the intuition directly: the de Sitter horizon is the natural holographic screen because finite observers live inside finite causal patches.

What Lambda means in the OPH branch

In the OPH account, Lambda is not one more local coupling. It is the global capacity datum of the screen. Local null-modular probes reconstruct stress-energy only up to the metric-proportional term, so the cosmological constant enters as the residual global scale.

The phrase cosmological constant derivation therefore names a capacity relation, not a claim that ordinary vacuum-energy estimates suddenly become small.
