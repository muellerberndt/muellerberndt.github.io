The canonical Cadence demo

A settling brain plays Doom.

A Deep Recursive Settlement Network plays shareware Doom from pixels alone — two grayscale retinas in, eight settled motor states out. No policy network, no backprop, no engine internals. It runs on your machine, and you can teach it by playing.

$ git clone https://github.com/muellerberndt/cadence-demos && cd cadence-demos/doom-lab $ python -m venv .venv && . .venv/bin/activate && pip install -r requirements.txt $ ./get_wad.sh && python server.py # open http://localhost:8666

Python 3.11+. The script fetches the freely distributable Doom shareware data; nothing is hosted and nothing phones home.

Watch it think

A live, rotatable 3D view of the nervous system: retina planes feed population clouds, sampled real wiring glows with its source's activity, and every committed witness batch sends a green learning wave through the network.

Teach it by playing

Take the controls in the teacher window. Every fourth game tic, your frame-and-buttons pair becomes a witness, admitted through atomic batched settlement while you play — the brain learns in the seams of the match.

Swap brains mid-game

A model dropdown hot-swaps checkpoints without stopping the game, and brains travel as single export files anyone can import — after full checkpoint validation.

Train your own

The full receipted pipeline ships with the demo: scripted privileged teacher, witness corpora, conditioned bootstrap with matched controls, DAgger correction rounds, and a foresight variant that learns a world model from measured outcomes.

What is claimed, precisely: learning in this demo is Cadence's supervised witness admission — batches commit only when the whole settlement qualifies, and refusals change nothing. Teaching is imitation; there is no reward-driven credit assignment here. Trained players are evaluated against a marginal-action control and a matched non-observer control before any capability claim is made.
