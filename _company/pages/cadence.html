The Cadence brain

A deep real-time brain that learns from experience.

Cadence connects local predictive models into a recursive settling network. Each model reads a part of its world. Together, they settle on what to do and learn from what happens.

The architecture

Intelligence through recursive settlement.

A Cadence brain is made of bounded, self-reading patches: local state, ports, records, error readback and feedback that can repair disagreement.

01 / Read

Local models

Each population has access to selected observations and connections. Ports define what it can read.

02 / Observe

Recursive feedback

Observer populations read represented activity and prediction error. Their responses join the same settlement.

03 / Settle

A coupled answer

The runtime jointly settles state, recomputing exact prediction errors with analytic derivatives and a global energy check.

04 / Learn

Experience persists

Accepted teaching and experience update local models. Explicit learning and memory mechanisms support further practice.

Cadence's Cortex and Brain interfaces expose this shared mathematical substrate. Perception, error observation and learning are part of the same connected system.

The research takes inspiration from cooperating cortical models. The code tests a computational hypothesis about intelligence; biological identification is a separate question.

Inside the brain / Interactive explainer

Watch a network find its answer.

A patch predicts. An observer reads its state and its error. A further observer can read that observer. All of them take part in the same settlement.

The building block

One small predictive unit.

Each patch holds a state and learned relation parameters. Its ports carry incoming signals. The difference between its state and its prediction is its prediction error.

The recursive connection

Observe an observer.

A population groups patches. An observer population reads another population's states and errors. Another observer can read those observers, using the same patch rule.

The coupled answer

Repair disagreement together.

Returning influence lets a later constraint change an earlier internal state. Sensory samples stay fixed during a solve. The answer is read from selected settled states.

What the animation means

Later constraints can change an earlier interpretation.

Run the settlement and inspect P0. Its state can change while the sensory input stays fixed. Add an observer level to include another population in the shared objective. Changing the signal retains internal activity until you repair it or reset it.

The returning arrows show influence through the objective's derivatives. Cadence's public read connections form an acyclic graph; these arrows do not add independently learned reverse connections.

Answering and learning

Settling changes activity. Learning changes relations.

For a query, weights and biases stay fixed while internal states settle. When Cadence admits an experience, supplied outcomes can constrain outputs and the relation parameters can change too, anchored to their values before that experience.

This illustration only settles activity. Recursive depth counts observers observing observers. It is distinct from the number of repair steps and from prediction into the future.

The patch equations behind the illustration

predictionᵢ = tanh(biasᵢ + Σ weightᵢⱼ × signalⱼ)
errorᵢ = stateᵢ − predictionᵢ
objective = ½ Σ errorᵢ² + 0.18/2 × Σ stateᵢ²

A signal can be a supplied input, another patch's state or an observed prediction error. Predictions and errors are recomputed from the current state; errors cannot be adjusted independently to conceal disagreement.

The illustration uses bounded state updates, exact derivatives through the error readbacks and backtracking for objective decrease. It stops at its stationarity tolerance or a 240-step budget. The objective's numerical “energy” does not measure electrical energy.

The positive activity penalty matters. For the corresponding acyclic, unclamped model in the idealized zero-penalty limit, the stationary answer reduces to forward substitution. Positive penalties or output constraints allow a different compromise. That difference alone does not establish better task performance.

The architectural difference

Feed-forward inference and joint settlement.

Comparison of the computation used to answer one query
QuestionOrdinary feed-forward networkCadence patch-net
How is an answer formed?Evaluate a directed sequence of layers.Repair the coupled internal state, then read the output.
Can a later constraint revise an earlier state?Not within the ordinary forward pass.Yes, through the shared objective during settlement.
What does another level add?Another transformation of preceding values.An observer can read preceding states and their exact prediction errors.
Can it learn from experience?Yes. Weight updates can use backpropagation, including online.Yes. Experience admission can repair states and relation parameters together.
What determines inference cost?The operations in the forward computation.The graph and the number of repair steps; qualification can exhaust its budget.

This compares ordinary feed-forward inference with the specified Cadence mechanism. Recurrent, iterative and hybrid neural architectures also exist. Useful depth, speed, retention and efficiency advantages need matched experiments. Sources: Deep Learning, chapter 6 and the Cadence architecture guide.

The product direction

A brain that stays in the loop.

We want robots to learn through operation, adapt when their body or environment changes, and preserve useful experience.

The first product engagement targets a bounded adaptation problem. The larger ambition is a reusable brain across bodies and tasks, with efficient deployment after bootstrapping.

Control-loop latency, retained skills and electrical energy per useful action are measurements for each deployment. The software evidence below gives us a starting point for those tests.
