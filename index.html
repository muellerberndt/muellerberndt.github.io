The one result

Reality and thought run on the same process.

Our physics program proves that a stable, shared world emerges when bounded observers compare their records where their views overlap and repair the disagreement locally. That is the solution to physics. Our AGI program builds machines that do exactly that, and reads the state they settle into as a thought. That is the key to AGI. The field at the top of this page runs the idea in miniature: hundreds of oscillators, each coupled only to its neighbours, find one rhythm with no conductor.

AI that keeps learning after it ships.

Today's AI models, such as ChatGPT, learn once. A training run in a datacenter costs months and very large sums, then the model is frozen and served from the cloud. The deployed model does not learn from what happens to it, and teaching it something new means another training run. General intelligence means handling situations nobody prepared for, which a system that cannot learn after release is unable to do.

Cadence brains learn continuously from their own experience, the way animals do. Each connection updates from local activity, so there is no separate training run, and a brain is small enough to run on the chip inside a robot. A robot can learn a new task on the job without forgetting the old ones.

The design came out of our physics, and it can be judged without the physics. The core library is open source so developers can adopt and test it. The brain designs we build on top of it for specific jobs, such as robot control, are proprietary.

Evidence · the open-source Cadence library on GitHub: brains that learn from one continuous stream of experience, with no retraining

Computers made of light.

Some physical systems, such as light passing through optics, naturally settle into a stable state. If a problem is set up so that the stable state is the answer, the physics performs the computation, with far less of the energy a digital chip spends moving numbers around. Cadence brains compute exactly this way: they settle into an answer.

Our mathematics describes computation by settling, so it gives the design equations for such hardware. The first target is an optical computer that runs a Cadence brain as a light field.
